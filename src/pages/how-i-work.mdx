## Understand the problem

I ask what needs to change, who it affects and what success looks like. I write down the rules and edge cases before building.

## Build and review

I use Claude Code and Codex to help implement small changes. I make the technical decisions and review the code for mistakes and unnecessary complexity.

## Test and release

I check the main workflows, failure cases and automated tests. I release small changes, then check errors, performance and usage.

## Keep the team informed

I share decisions, progress and problems. I keep instructions and notes with the code so others can pick up the work. I stay involved after release.
