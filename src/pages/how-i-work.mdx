<div class="not-prose my-10 grid gap-4 sm:grid-cols-2">
  <div class="card fx p-6">
    <p class="font-mono text-xs text-accent">01</p>
    <h2 class="mt-2 text-lg font-semibold">Understand the problem</h2>
    <p class="mt-2 text-sm leading-relaxed text-muted">I ask what needs to change, who it affects and what success looks like. I write down the rules and edge cases before building.</p>
  </div>
  <div class="card fx p-6" style="--d:60ms">
    <p class="font-mono text-xs text-accent">02</p>
    <h2 class="mt-2 text-lg font-semibold">Build and review</h2>
    <p class="mt-2 text-sm leading-relaxed text-muted">I use Claude Code and Codex to help implement small changes. I make the technical decisions and review the code for mistakes and unnecessary complexity.</p>
  </div>
  <div class="card fx p-6" style="--d:120ms">
    <p class="font-mono text-xs text-accent">03</p>
    <h2 class="mt-2 text-lg font-semibold">Test and release</h2>
    <p class="mt-2 text-sm leading-relaxed text-muted">I check the main workflows, failure cases and automated tests. I release small changes, then check errors, performance and usage.</p>
  </div>
  <div class="card fx p-6" style="--d:180ms">
    <p class="font-mono text-xs text-accent">04</p>
    <h2 class="mt-2 text-lg font-semibold">Keep the team informed</h2>
    <p class="mt-2 text-sm leading-relaxed text-muted">I share decisions, progress and problems. I keep instructions and notes with the code so others can pick up the work. I stay involved after release.</p>
  </div>
</div>
