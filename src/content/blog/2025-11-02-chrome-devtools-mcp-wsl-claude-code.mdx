### 1. Install Chrome for Testing

<p class="post-file"><Icon name="ph:terminal-window" /> WSL terminal</p>

```bash
npx -y @puppeteer/browsers install chrome@stable --path ~/.local/share/chrome-for-testing
```

Save the executable path printed by the installer. Step 2 needs it.

### 2. Configure MCP Server

Add this server entry under your project:

<p class="post-file"><Icon name="ph:file-code" /> ~/.claude.json</p>

```json
{
  "projects": {
    "/path/to/your/project": {
      "mcpServers": {
        "chrome-devtools": {
          "type": "stdio",
          "command": "npx",
          "args": [
            "-y",
            "chrome-devtools-mcp@latest",
            "-e",
            "/home/username/.local/share/chrome-for-testing/chrome/linux-VERSION/chrome-linux64/chrome",
            "--isolated"
          ],
          "env": {}
        }
      }
    }
  }
}
```

<div class="card post-rules post-solo not-prose fx">
  <p class="eyebrow">What to change, and what the flags do</p>
  <ul>
    <li><span class="post-trigger">/path/to/your/project</span><Icon name="ph:arrow-right" /><span>Replace with your project path</span></li>
    <li><span class="post-trigger">/home/username/…/chrome</span><Icon name="ph:arrow-right" /><span>Replace with the Chrome path from step 1</span></li>
    <li><span class="post-trigger">`-e`</span><Icon name="ph:arrow-right" /><span>Selects the executable</span></li>
    <li><span class="post-trigger">`--isolated`</span><Icon name="ph:arrow-right" /><span>Uses a temporary browser profile</span></li>
  </ul>
</div>

### 3. Set permissions

To allow these tools without individual prompts, add the wildcard. It covers all Chrome DevTools tools.

<p class="post-file"><Icon name="ph:file-code" /> ~/.claude/settings.json</p>

```json
{
  "permissions": {
    "allow": [
      "mcp__chrome-devtools__*"
    ]
  }
}
```

### 4. Reload VS Code

Press <kbd class="key">Ctrl</kbd> <kbd class="key">Shift</kbd> <kbd class="key">P</kbd>, then run **Developer: Reload Window**.

### 5. Check the connection

<p class="post-file"><Icon name="ph:terminal-window" /> WSL terminal</p>

```bash
claude mcp list
```

<p class="post-status not-prose"><Icon name="ph:check-circle" />`chrome-devtools: ... - ✓ Connected`<span>What you should see</span></p>

## If it does not connect

<div class="card post-rules post-solo not-prose fx">
  <p class="eyebrow">Symptom, then what to check</p>
  <ul>
    <li><span class="post-trigger">Chrome not found</span><Icon name="ph:arrow-right" /><span>Check the installed version folder and update the `-e` path.</span></li>
    <li><span class="post-trigger">Target closed</span><Icon name="ph:arrow-right" /><span>Check whether Chrome starts. If you are launching Windows Chrome, try the Linux installation above.</span></li>
    <li><span class="post-trigger">Server missing</span><Icon name="ph:arrow-right" /><span>Check the JSON syntax, reload VS Code and inspect the extension logs.</span></li>
    <li><span class="post-trigger">Permission denied</span><Icon name="ph:arrow-right" /><span>Check the allow list in your global or project settings.</span></li>
  </ul>
</div>
