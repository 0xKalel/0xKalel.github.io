## Cache what customers share

The catalog repeated the same database queries on every visit. I reduced the queries, added indexes, and used cached data to build the page on the server.

## Make payment retries safe

Payments can time out, and customers may try again. I rebuilt the payment flow so each attempt uses the current amount due and prevents duplicate charges.

<div class="post-media not-prose fx">
  <div class="post-screen-img"><Image src={checkout} alt="StoragePal payment page with all payment details together" widths={[240, 480]} sizes="200px" /></div>
  <div>
    <h3>Payment rules</h3>
    <ul class="post-checks">
      <li>Charge only the current invoice</li>
      <li>Never start a second payment while one is in progress</li>
      <li>Retry failed payments and flag blocked payments for review</li>
      <li>Check the payment status before each reminder</li>
    </ul>
    <dl class="post-figures"><div><dt>3 <span class="to">→</span> 1</dt><dd>pages in the payment flow</dd></div></dl>
  </div>
</div>

## Price transport by the real job

Transport used to have a flat price for each region. I built one pricing system based on the details of each job, with input from customer support and logistics.

## Keep AI proposals inside the business rules

The shopping assistant suggests a cart from a description or photo. The server checks every item and calculates the price.
